# v1.5.0（停止更新）

88API-Nano-Banana 停止更新，这是最后一个版本。

- Gemini 生图已并入 **[88API-Image-Gen](https://github.com/blackdm666/88API-image-gen) v3.0.0**：同一个插件支持 `gemini-3.1-flash-image`、`gemini-nano-banana-2.1`、`gemini-3-pro-image`，以及 GPT Image、Grok、Seedream、Midjourney；比例、1K/2K/4K 和参考图上限按 88API 文档站的模型清单校验。
- 安装 88API-Image-Gen 后，第一次运行会自动把本插件的 Key 和默认模型从 `~/.88api/nano-banana.json` 迁移过去，不需要重新配置。
- 本插件仍可继续使用，功能与 v1.4.0 相同；每次运行会在 stderr 打印一行停更提示（不影响 `--json` 输出）。技能说明会让 Agent 优先使用已安装的 88API-Image-Gen，并在对话中提示一次停更。
- 插件清单和市场描述标注「已停止更新」。
