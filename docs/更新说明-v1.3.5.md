# v1.3.5 更新说明

本版本为批量任务加入单进程顺序调度，并补充 Codex Auto 模式外网审批故障说明；不改变 88API 请求端点、模型或单次请求计费方式。

## 单进程批量

- 新增 `--batch-inline`，一次接收最多 20 条不同提示词。
- 新增 `--batch`，读取 JSON 字符串数组或 `{ "prompts": [...] }`。
- 批量请求在同一插件进程中顺序执行，减少每张图片分别启动命令造成的重复外网审批。
- 每条提示词仍是独立付费请求；任一任务失败后停止后续任务，不自动重发未知状态请求。
- 增加 `[序号/总数] 正在向 88API 提交图片请求` 日志，用于区分已启动任务与尚未发送的任务。

## 审批错误提示

- 明确区分 Codex 外网执行授权、沙箱网络权限或审批服务 429 与 88API 的 HTTP 错误。
- 对明确在请求发出前被拦截的任务，说明其没有到达 88API、没有对应日志，也不会产生该部分费用。
- 提供 **General（通用）→ Permissions（权限）→ Full access（完全访问）** 操作步骤，并提示完全访问会取消本地沙箱与审批边界。

## 版本

- 插件版本升级至 `1.3.5`。
