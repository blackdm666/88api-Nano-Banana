# v1.4.0 更新说明

不再只限 Codex：同一个插件可以在 Claude Code、ZCode、DeepSeek Harness 以及能运行本机 Node.js 命令的其它 Agent 客户端中使用。与 88API-Image-Gen v2.3.0 同一套改造。

- **Claude Code / ZCode 插件**：新增 `plugins/88api-nano-banana/.claude-plugin/plugin.json` 和仓库根目录 `.claude-plugin/marketplace.json`。Claude Code 用 `/plugin marketplace add blackdm666/88api-Nano-Banana` 安装；ZCode 兼容同一格式，在 设置 → Plugins → Add marketplace 中添加本仓库。
- **技能文件夹自带脚本**：`generate.mjs` 从 `plugins/88api-nano-banana/scripts/` 移到 `plugins/88api-nano-banana/skills/88api-nano-banana/scripts/`，整个技能文件夹可以直接复制到其它客户端的技能目录。
- **Key 改存客户端通用位置**：`~/.88api/nano-banana.json`。旧版 `~/.codex/88api-nano-banana-config.json` 第一次使用时自动复制过来，旧文件保留，并在保存时同步更新，未升级的旧版插件仍可使用。
  - 新增环境变量 `API88_KEY`：优先于配置文件，不写盘。原有的 `NANO_BANANA_API_KEY` 仍然可用，优先级在配置文件之后（与以前一致）。
  - 新增环境变量 `API88_CONFIG_DIR`：改配置目录（设置后不再读取、同步旧路径）。
  - `--get-config` 新增「Key来源」「旧版配置同步」两项。
- **分阶段报错**（以前所有网络失败都报成“状态未知”）：
  - `request was not sent`（请求未发出）：连接没建立，没有扣费，可以直接重新提交。
  - `stage: submit`：已发出、没收到响应，状态未知，可能已扣费，不自动重发。
  - `stage: read-result`：已收到成功响应头、读取响应体时中断，已计费。
  - `stage: download`：结果是链接时下载失败。下载前先把链接存到输出目录的 `*.pending-download.json`，免费重试 3 次（间隔 2 秒、5 秒）；仍失败时保留该文件，用 `--retry-download <文件>` 只下载、不发新的付费请求。88API 2026-10-22 起默认直接返回图片数据，通常不会走到这一步。
  - 批量中途失败时，列出本次已保存的图片，并说明剩余提示词没有提交、没有费用。
- **提交记录与 `--job-status`**：每次付费运行在 `~/.88api/nano-banana-jobs/` 写一份记录，每个请求发出前就先记下。客户端因超时把命令结束后，运行 `--job-status <任务号>`（不带参数列出最近几次）即可查清每个请求的实际状态。不发请求、不收费。记录格式与 88API-Image-Gen 相同。
- **`--json`**：付费运行结束时多输出一行机器可读结果，结构与 `--job-status` 相同。
- **技能说明**：去掉 Codex 专属表述；新增「长任务与客户端命令超时」一节（Claude Code 付费命令一律后台运行，任何客户端中断后先查 `--job-status`）；补充各失败阶段的处理方式。Codex Auto 模式审批的说明保持不变。
- `--self-test` 新增：旧配置迁移与同步、Key 优先级、分阶段报错（含一次真实的拒绝连接）、提交记录各状态与进程中断识别。

升级后：Codex 新建任务，Claude Code / ZCode 新开对话，以重新加载技能。
